Referências por URL

Cole links de artigos existentes. O plugin extrai o texto e envia como contexto para a IA gerar um conteúdo mais embasado.

AES-256 nas chaves

Todas as API keys são criptografadas antes de salvar. As chaves nunca trafegam em texto puro.

Drag & Drop de imagens

Arraste uma imagem para qualquer lugar da janela. Um modal pergunta se quer usar como capa ou inserir no corpo do texto.

Defina o tom de voz, estilo jornalístico e instruções fixas que valem para todas as gerações do site.

Gemini Search ativo
